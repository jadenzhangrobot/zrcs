# openArm 抓取实验场景

`robot.xml` 在双臂机械臂前方提供了一套带真实碰撞的桌面抓取场景。场景默认使用
MuJoCo 动力学模式，三个物件都带 `freejoint`，可以受重力、桌面、夹爪和放置框碰撞影响。

## 场景组成

- 桌面 `grasp_table`：桌面高度 `Z=0.375 m`，近边缘与机械臂底座之间留有间隙。
- 红色方块 `grasp_object_red`：初始世界坐标 `(0.22, -0.10, 0.412)`。
- 蓝色圆柱 `grasp_object_blue`：初始世界坐标 `(0.27, 0.00, 0.412)`。
- 绿色球体 `grasp_object_green`：初始世界坐标 `(0.30, 0.10, 0.405)`。
- 放置框 `workpiece`：框中心参考点 `grasp_bin_center` 的世界坐标约为
  `(0.36, 0.22, 0.470)`；框体与最近桌边保留约 `0.08 m` 的安全距离，
  同时位于左臂可达范围内。

每个物件均提供同名抓取参考点：

- `grasp_object_red_point`
- `grasp_object_blue_point`
- `grasp_object_green_point`

放置框同时提供 `workpiece_origin`，GUI 使用工件相对轨迹显示时会自动识别该参考点。

## 建议实验流程

1. 在仿真界面点击“重新加载”，确认桌子没有与底座相交。
2. 打开夹爪，从目标物件上方约 `0.08-0.12 m` 的位置接近。
3. 竖直下降到物件抓取点，使两个夹指位于物件两侧。
4. 低速闭合夹爪，抬高约 `0.10 m`，确认物件没有滑落。
5. 移动到 `grasp_bin_center` 上方，下降后打开夹爪。
6. 抬起机械臂，观察物件是否稳定留在放置框内。

`mujoco.xml` 未启用 `kinematicOnly`，因此 RT MuJoCo 后端会执行接触和重力动力学。
GUI 仿真面板主要用于关节状态显示；抓取接触的最终结果应以 RT 动力学仿真状态为准。

## 抓取手感说明

物件是实体 freejoint（有质量、碰撞、重力），不是幽灵。若看起来像“假体/穿模”，常见原因：

1. 夹爪姿态偏侧向，没有包住物体中心
2. 夹爪位置环 `kp` 太小，闭合目标又追到 0，接触后夹紧力掉光
3. 接触 `solref` 偏软，短时穿透观感明显

当前场景已提高物件摩擦与接触刚度，并把左/右夹爪 PD 提到 `kp=120, kd=2`。
行为树闭合目标保留约 `0.08 rad`，用于维持持续夹紧力。

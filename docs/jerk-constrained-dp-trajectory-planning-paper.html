A Jerk-Constrained Global Time-Optimal Trajectory Planning Framework Using Dynamic Programming

摘　要

针对数控系统与机器人沿给定几何路径运动时，加加速度（jerk）约束导致状态维数提升、局部可行性与全局时间最优性难以兼顾的问题，本文提出一种基于动态规划的 jerk 约束全局时间最优轨迹规划框架。该方法首先在路径参数域内建立速度、加速度与 jerk 到各执行轴运动约束的严格映射，并利用 S 型曲线最短变速距离执行前向—后向可达包络计算，以压缩后续搜索空间；随后将离散路径接点上的状态表示为速度—切向加速度二元组，构造分层有向无环状态图。图中每条边由 jerk 受限局部轨迹生成器进行可行性判定和最短时间求解，动态规划依据 Bellman 最优性原理选择总时间最小的连续状态链。进一步地，本文提出基于可达区间的自适应加速度采样、不可行边提前剪枝以及支配状态消除策略，从而降低状态图规模。所提出方法在离散状态图上具有全局最优性，重建轨迹在局部求解器正确且共享边界状态一致时满足速度、加速度和 jerk 连续性约束；随着路径与状态网格加密，其解在常规正则条件下逼近连续问题最优解。该框架兼容解析 S 曲线求解器与 Ruckig 等在线轨迹生成器，适合在非实时层完成全局规划、在实时层执行分段轨迹。本文同时给出面向 CNC 折线、圆弧和机器人关节路径的可复现实验协议。

关键词：轨迹规划；时间最优；加加速度约束；动态规划；S 型曲线；路径参数化；Ruckig

Abstract

This paper presents a dynamic-programming framework for globally time-optimal path parameterization under jerk constraints. A prescribed geometric path is first transformed into the path-coordinate domain, where joint or Cartesian velocity, acceleration, and jerk limits are expressed as state-dependent inequalities. A jerk-limited forward-backward reachable envelope based on minimum S-curve transition distances is then computed to reduce the admissible velocity range. At each discretized path junction, a state lattice over path velocity and tangential acceleration is constructed. Every inter-layer edge is evaluated by a jerk-limited local trajectory generator, which returns both feasibility and minimum transition time. Dynamic programming subsequently recovers the minimum-time continuous state chain according to Bellman's principle of optimality. Adaptive acceleration sampling, reachable-interval pruning, and dominance elimination are introduced to control graph complexity. The resulting solution is globally optimal on the discretized graph and is jerk-feasible when all local transitions satisfy the projected constraints and share identical boundary states. Under standard regularity and consistency assumptions, grid refinement drives the discrete solution toward the optimum of the continuous problem. The framework supports both analytical S-curve solvers and online trajectory generators such as Ruckig, enabling global planning in a non-real-time layer and deterministic segment execution in a real-time controller.

Keywords: trajectory planning; time-optimal path parameterization; jerk constraints; dynamic programming; S-curve; reachable set

1　引言

沿给定几何路径的时间最优参数化是机器人、数控机床、激光加工和高速搬运系统中的基础问题。传统二阶方法通常在路径坐标中约束速度和加速度，并通过前向—后向积分获得时间最优速度曲线。然而，当控制器同时限制 jerk 时，系统状态由单一速度扩展为速度与加速度的组合；未来可达速度不仅取决于当前位置和速度，也取决于当前加速度。因而，基于 v2 = v02 + 2aΔs 的二阶扫描无法为加速度建立连续边界，短段、急剧限速点和非零接点加速度容易造成局部轨迹生成器不可行。

另一类工程方案为每个几何段独立生成七段式 S 曲线，并强制接点加速度为零。该策略容易实现且通常可行，但频繁清零加速度会损失跨段加速能力，不能利用前方较长路径提前建立加速度，也难以获得全局最短执行时间。直接求解连续三阶最优控制问题则存在奇异曲线、切换结构复杂、数值敏感以及实时性不足等困难。

本文采用“速度可达包络预处理 + 二维状态图 + 局部精确可行性判定 + 动态规划”的思路，将难以直接处理的连续全局问题转化为结构清晰的分层最短路径问题。其主要贡献如下：

  1. 建立包含路径曲率项的逐轴三阶约束投影，使标量路径速度、切向加速度和路径 jerk 与各执行轴的速度、加速度和 jerk 限制保持一致。
  2. 提出基于 S 型最短变速距离的双向速度包络，作为动态规划前的安全上界与剪枝工具；零加速度状态始终作为保底候选，因此搜索失败可与输入本身不可行明确区分。
  3. 将接点状态离散为 (v, a)，使用 jerk 受限局部求解器定义图边，以动态规划获得离散图上的全局最短时间状态链，并保持段间速度和加速度连续。
  4. 给出自适应采样、可达区间传播、边缓存与支配剪枝方法，以及与 NRT/RT 分层控制架构相匹配的工程实现方案。

2　相关工作

2.1　二阶时间最优路径参数化

Bobrow 等和 Shin–McKay 奠定了沿指定路径进行最短时间参数化的经典框架，通过将机器人动力学约束转化为路径加速度区间，沿最大/最小加速度场积分得到速度极限曲线。后续研究利用凸优化和可达性分析改善了鲁棒性。TOPP-RA 将离散路径上的二阶约束表示为可达集合传播，在速度—平方速度变量下获得快速而稳定的参数化结果。这类方法对速度与加速度约束非常有效，但 jerk 引入了加速度状态，使一维可达区间不再充分。

2.2　三阶约束与 S 型曲线

jerk 受限轨迹通常采用分段常 jerk 的 S 型曲线，能够降低机械冲击、结构振动和伺服跟踪误差。在线轨迹生成器可在给定位置、速度和加速度边界状态下实时求解局部时间最优轨迹。Ruckig 进一步支持任意目标状态和多自由度同步，适合作为局部边求解器。然而，在线轨迹生成解决的是“当前状态到单一目标状态”的问题，本身不决定多个路径接点的全局边界状态。

2.3　本文方法定位

本文不替代局部 S 曲线或在线轨迹生成器，而是在其上层增加全局边界状态选择。与逐段零加速度方法相比，动态规划允许非零加速度跨越接点；与直接连续三阶最优控制相比，分层图避免显式追踪复杂的奇异曲线；与只对速度做 jerk 惩罚的前瞻相比，本文将加速度纳入状态并逐边验证，从而形成可执行的连续状态链。

3　问题建模

3.1　路径参数化

设已知几何路径为 q(s) ∈ ℝm，其中 s ∈ [0, S] 为弧长或单调路径参数，m 为关节或笛卡尔轴维数。定义路径速度、切向加速度和路径 jerk：

v = ṡ ≥ 0，　a = s̈，　j = s⃛ (1)

由链式法则，各轴的一至三阶时间导数为：

q̇ = qsv (2)
q̈ = qssv2 + qsa (3)
q⃛ = qsssv3 + 3qssva + qsj. (4)

式 (4) 表明，仅限制标量路径 jerk 并不能自动保证每个执行轴的 jerk 合法；曲率变化项 qsssv3 和速度—加速度耦合项 3qssva 必须同时考虑。

3.2　运动学与工艺约束

对第 k 个轴给定速度、加速度与 jerk 上下界：

|q̇k| ≤ Vk，　|q̈k| ≤ Ak，　|q⃛k| ≤ Jk (5)

将式 (2)–(4) 代入式 (5)，可得到依赖于 (s, v, a) 的路径 jerk 可行区间：

j ∈ [jmin(s,v,a), jmax(s,v,a)] (6)

若某轴 qs,k 接近零，则不能直接除以该项，而应保留原始线性不等式并求所有轴约束的交集。除此之外，还可加入工艺进给上限、曲率向心加速度限制、接点容差、速度非负以及起终点状态约束。

3.3　优化目标

给定起终状态 x0 = (0, v0, a0) 和 xf = (S, vf, af)，目标是在满足式 (2)–(6) 及路径连续性的条件下最小化总时间：

T* = min　∫0S 1v(s)ds. (7)
离散全局最优性的含义：本文算法保证在给定路径网格、状态候选集和局部边求解器所定义的有限有向图上取得全局最短时间。它不在有限网格下声称等于连续最优控制问题的精确全局最优解。

4　基于动态规划的全局规划框架

4.1　S 型曲线速度可达包络

对零边界加速度的一维速度转换，记 Δv = |v1 − v0|，最大切向加速度和 jerk 分别为 A 与 J。若 Δv ≤ A2/J，加速度轮廓为三角形；否则为含恒加速度平台的梯形。最短转换时间为：

Ttr = { 2√(Δv/J),　Δv ≤ A2/J；　 Δv/A + A/J,　其他 } (8)

由于该 S 曲线关于时间中点对称，最短转换距离为：

dmin(v0,v1) = v0 + v12 Ttr. (9)

对每个长度为 Δsi 的路径段，通过二分求解满足 dmin ≤ Δsi 的最大入口或出口速度。一次后向扫描保证能够减速到未来限速点，一次前向扫描保证能够从起始状态加速到接点速度。该包络采用零加速度边界，因此是后续二维搜索的保守可行基线，而不是最终加速度解。

4.2　速度—加速度状态格点

将路径离散为 N 个区间和 N+1 个接点 si。第 i 层候选状态定义为：

Xi = { xi,r = (vi,r, ai,r) | r = 1,…,Mi }. (10)

速度候选限制在双向包络和局部几何速度上界以内；加速度候选首先根据式 (3) 求得逐轴合法区间，再在区间内自适应采样。除均匀样本外，候选集加入以下高价值状态：

  • 零加速度状态，用作可行保底并对应传统逐段 S 曲线策略；
  • 由左右段等效恒加速度估计得到的候选；
  • 前一层可达区间边界及最大/最小 jerk 积分预测值；
  • 上一轮粗网格最优状态邻域内的局部加密样本。

4.3　局部边可行性与代价

仅允许相邻层之间连边。对候选状态 xi,r 和 xi+1,k，局部求解器在位移 Δsi 上求解：

(si,vi,r,ai,r) → (si+1,vi+1,k,ai+1,k). (11)

若存在满足式 (5)–(6) 的 jerk 受限轨迹，则建立有向边并将最短转换时间记为 ci(r,k)；否则边代价为 +∞。局部求解可以采用解析七段式 S 曲线，也可以调用支持任意边界速度和加速度的在线轨迹生成器。为避免仅在端点合法而区间内部违规，需对解析切换时刻、曲率极值点以及必要的区间样本执行逐轴约束检查。

4.4　Bellman 递推

定义 Vi(r) 为从第 i 层状态 xi,r 到终点的最短剩余时间，则：

Vi(r) = mink [ ci(r,k) + Vi+1(k) ]. (12)

终点合法状态的代价为 0，其余状态为 +∞。由后向递推记录最优后继索引，再从指定起点状态前向回溯，即得到全局状态链和各段局部轨迹。

算法 1　Jerk-DP 全局时间最优轨迹规划
  1. 离散路径并计算 qs、qss、qsss 及局部工艺约束。
  2. 根据式 (8)–(9) 执行后向和前向扫描，获得保守速度包络。
  3. 在每个接点生成 (v,a) 候选，加入零加速度与可达边界状态。
  4. 用快速必要条件剔除明显不可达的候选状态对。
  5. 调用局部 jerk 受限求解器计算剩余边的可行性和最短时间。
  6. 从终点执行式 (12) 的反向动态规划，并保存最优后继。
  7. 从起点回溯状态链，拼接局部轨迹并进行全路径约束复核。
  8. 若误差或保守度超过阈值，仅在最优链邻域加密网格并重复步骤 3–7。

4.5　剪枝与自适应细化

朴素状态图的边数随每层候选数平方增长。本文采用三类剪枝：首先利用 S 曲线最短距离排除不满足必要条件的状态对；其次传播每个候选状态在下一层可达的速度和加速度区间，仅对区间相交状态调用局部求解器；最后，若两个同层状态具有近似相同的 (v,a)，且其中一个到达代价更大、未来可达集合不更优，则删除被支配状态。局部边结果按量化边界状态缓存，使粗到细多轮规划能够复用计算。

5　正确性与复杂度分析

命题 1（离散图全局最优性）。若状态图为按路径接点分层的有向无环图，且每条边代价等于对应局部边界状态之间的最短可行时间，则式 (12) 回溯所得路径是该状态图中从指定起点到指定终点的全局最短时间路径。

证明要点：任意全局最优路径在第 i 层选定某一后继状态后，其剩余子路径必须是该后继到终点的最优路径，否则可用更短子路径替换并改进全局解，与最优性矛盾。分层图无环，故从终点反向应用 Bellman 递推即可覆盖所有候选路径。

命题 2（拼接可行性）。若每条选中边均满足位置、速度、加速度和 jerk 约束，且相邻边共享完全相同的接点位置、速度和加速度，则拼接轨迹的位置、速度和加速度连续，并在除有限 jerk 切换时刻外满足三阶约束。

证明要点：每段内部可行性由局部求解器保证；共享边界状态保证零至二阶连续。jerk 允许在约束范围内分段常值并发生有限跳变，因此不要求 jerk 本身连续。若应用还约束 snap，则必须将 jerk 纳入接点状态并提升动态规划维数。

命题 3（相对零加速度基线的非劣性）。若每个内部接点候选集都包含 a=0，且速度候选包含基线 S 曲线包络给出的接点速度，则动态规划结果的总时间不大于逐段零加速度基线。

证明要点：基线对应状态图中的一条完整可行路径。动态规划在包含该路径的候选集合上取最小代价，因此其代价不会更大。

5.1　连续问题逼近

在可行域紧致、约束函数连续、局部最短时间关于边界状态下半连续、路径离散误差一致收敛，并且候选网格最大间距趋于零的条件下，离散最优代价构成连续最优代价的可行上界序列。采用嵌套网格且保留上一层候选时，该上界单调不增。严格收敛证明还需处理奇异状态和非唯一局部解，本文将其作为后续理论工作；因此实验中必须报告网格收敛曲线，而不能仅给出单一分辨率结果。

5.2　计算复杂度

设每层最多有 M 个状态，路径区间数为 N，单次局部边求解代价为 Cedge。完全连接相邻层时，时间复杂度为 O(NM2Cedge)，存储所有边需要 O(NM2) 空间。若只保留每个状态的最优代价和后继索引，动态规划主体空间可降至 O(NM)；结合可达区间剪枝，实际平均出度记为 K ≪ M，则边求解复杂度降为 O(NMKCedge)。

6　工程实现

6.1　数据结构与数值策略

推荐将路径几何与规划状态分离。几何层保存段长、切线、曲率及其导数；状态层只保存接点速度、加速度、累计代价和最优后继；边缓存保存局部求解结果。所有内部量应使用统一 SI 单位，并为位置、速度、加速度、jerk 分别设置尺度归一化，避免短段条件下的浮点判定失稳。

struct JunctionState {
    double velocity;
    double acceleration;
    double cost_to_go;
    int best_next;
};

struct TransitionEdge {
    bool feasible;
    double duration;
    LocalTrajectory trajectory;
};

6.2　NRT/RT 分层执行

全局状态图搜索、候选自适应加密和边缓存适合放在非实时层。规划完成后，只向实时层发送每段几何、局部速度上限和目标 (v,a)。实时层使用与离线边验证相同的约束和局部求解器逐周期采样，并将上一周期输出状态传入下一周期。段间不得重新假设加速度为零，也不得在 NRT 和 RT 之间使用不同的单位、最大速度或 jerk 参数。

6.4　鲁棒性处理

  • 当路径段过短时，优先进行几何合并或联合多段求解，避免大量近零位移边。
  • 起终状态必须显式验证；若请求速度超过局部上限，应返回输入错误而不是静默截断。
  • 局部求解失败应记录段号、边界 (v,a) 和约束参数，便于复现实验。
  • NRT 规划完成后应使用 RT 完全相同的参数再次批量回放，检测参数通路或单位失配。
  • 对动态倍率变化，需要区分单纯时间缩放与在线重规划；前者只有在控制器实现保持状态一致时才不破坏约束。

8　讨论与局限

本文框架的主要优势是把全局边界状态决策与成熟的局部 jerk 轨迹生成器解耦，并通过动态规划获得可解释的最优性。由于路径接点按顺序形成有向无环图，算法不存在一般图搜索中的循环问题，且天然适合并行计算同一层的局部边。

其局限首先来自状态离散。有限候选集可能遗漏连续最优解附近的窄可行通道，尤其是在路径导数退化、约束活跃集快速切换或边界加速度接近极限时。其次，若局部边只使用标量 A 和 J，而没有验证式 (4) 的逐轴约束，则所得轨迹只能称为路径标量 jerk 可行，不能称为机器人或机床各轴三阶可行。再次，动态障碍、在线模型变化和闭环跟踪误差不在本文离线最优模型内，需要滚动时域重规划或鲁棒约束扩张。

标题中的“Global Time-Optimal”应在正文和实验中始终限定为离散状态图上的全局最优。若要进一步证明连续全局最优，需要给出网格一致性、局部边精确性、奇异状态处理和误差上界的严格理论结果。投稿时建议将标题保留，同时在摘要首处明确“globally optimal over the discretized state graph”，以降低审稿人对过度声明的质疑。

9　结论

本文提出一种 jerk 约束全局时间最优轨迹规划框架。该方法使用 S 曲线双向包络压缩速度范围，以接点速度和加速度构造分层状态图，通过局部 jerk 受限求解器定义可行边及时间代价，并利用动态规划选择总时间最小的连续状态链。理论分析表明，该方法在离散图上满足全局最优性，局部边可行且共享边界状态一致时，重建轨迹保持位置、速度和加速度连续。与逐段零加速度 S 曲线相比，只要候选集保留基线状态，动态规划结果在总时间上具有非劣性。

下一步工作包括完成逐轴三阶约束投影，实现粗到细自适应状态格点和并行边求解，建立与非线性规划参考解的系统对比，并在真实 CNC 与机器人平台上验证轨迹时间、约束裕度和实时执行可靠性。

Input:
    sampled path s[0..N], geometry derivatives, axis limits
    start state (v0, a0), terminal state (vf, af)

velocity_cap = project_geometric_and_axis_velocity_limits()
velocity_env = jerk_limited_backward_forward_scan(velocity_cap)

for i in 0..N:
    states[i] = sample_admissible_velocity_acceleration_states(
        s[i], velocity_env[i], axis_limits)
    states[i].insert(zero_acceleration_baseline_state)

cost[N][terminal_state] = 0
for i in N-1 down to 0:
    reachable_pairs = interval_prune(states[i], states[i+1])
    parallel for (r, k) in reachable_pairs:
        edge = solve_local_jerk_limited_transition(
            s[i+1] - s[i], states[i][r], states[i+1][k])
        if edge.feasible and verify_axis_constraints(edge):
            candidate = edge.duration + cost[i+1][k]
            relax(cost[i][r], next[i][r], candidate, k)

state_chain = backtrack(next, specified_start_state)
trajectory = concatenate_local_trajectories(state_chain)
verify_full_trajectory(trajectory)
return trajectory

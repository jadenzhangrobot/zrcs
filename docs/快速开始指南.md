# 快速开始指南

## 系统要求

### 必需依赖

| 依赖 | 版本 | 用途 |
|------|------|------|
| CMake | >= 3.18.1 | 构建系统 |
| C++17 编译器 | GCC 7+ / MSVC 2017+ | 编译 |
| Qt5 | 5.12+ | GUI 框架 |
| Boost | 1.65+ | 共享内存 |
| Protobuf | 3.0+ | 消息序列化 |
| Abseil | -- | 日志/工具（Protobuf 依赖） |
| Python3 | 3.6+ | 配置脚本 |
| ZMQ / cppzmq | -- | 网络通信 |

### 依赖安装

#### Linux (Ubuntu/Debian)

```bash
sudo apt-get update
sudo apt-get install -y \
    cmake g++ \
    qtbase5-dev qt5-qmake \
    libboost-dev libboost-system-dev \
    libprotobuf-dev protobuf-compiler \
    libabsl-dev \
    libzmq3-dev libcppzmq-dev \
    python3
```

#### Windows (MSYS2)

```bash
pacman -S mingw-w64-x86_64-cmake \
          mingw-w64-x86_64-gcc \
          mingw-w64-x86_64-qt5-base \
          mingw-w64-x86_64-boost \
          mingw-w64-x86_64-protobuf \
          mingw-w64-x86_64-zeromq \
          mingw-w64-x86_64-cppzmq \
          mingw-w64-x86_64-abseil-cpp \
          mingw-w64-x86_64-python3
```

#### Windows (vcpkg)

```bash
vcpkg install qt5-base boost-interprocess protobuf abseil zmq cppzmq
```

## 构建步骤

### Linux

```bash
cd zrcs-dev
mkdir build && cd build
cmake ..
make -j$(nproc)
```

### Windows (MinGW)

```bash
cd zrcs-dev
mkdir build && cd build
cmake -G "MinGW Makefiles" ..
mingw32-make
```

### 指定构建模式

```bash
# 标准模式（默认）
cmake ..

# 实时模式（需要 Xenomai + EtherCAT）
cmake -DBUILD_MODE=realtime ..

# 仿真模式（需要 CoppeliaSim）
cmake -DBUILD_MODE=simulation ..
```

## 运行步骤

需要打开 3 个终端：

### 终端 1: 启动 NRT 进程

```bash
cd build
./bin/zrcsnrt
```

预期输出：
```
ZRCS Non-Real-Time Process Started
[NRT] SharedBlock initialized
[ZMQServer] Initialized on tcp://*:5555
[NRT] ZMQ server started, waiting for commands...
```

### 终端 2: 启动 GUI

```bash
cd build
./bin/zrcsgui
```

GUI 状态栏应显示：`已连接到 NRT 进程 (ZMQ)`

### 终端 3: 发送测试命令（可选）

```bash
cd build
./bin/zmqClientTest
```

或使用 Python：
```bash
python3 tool/zrcs_client.py
```

## 核心概念

### 三层架构

```
上位机/客户端 (Python/C++/GUI)
        | ZMQ + Protobuf (TCP:5555)
    NRT 进程 (zrcsnrt)
        | 共享内存 (Boost IPC)
    RT 进程 (zrcsrt)
```

- **GUI 进程** -- 用户界面，发送控制命令，显示状态
- **NRT 进程** -- 非实时核心，ZMQ 服务器，运动规划
- **RT 进程** -- 实时控制环，直接驱动伺服

### 通信方式

1. **ZMQ（推荐）** -- 上位机与 NRT 进程通信，支持远程连接
2. **共享内存** -- NRT 与 RT 进程通信，低延迟
3. **自动故障转移** -- ZMQ 失败时 GUI 自动使用共享内存

## 常见配置修改

### 修改 ZMQ 端口

NRT 侧 (`zrcsNrt/zmqServer.h`):
```cpp
static constexpr const char* ENDPOINT = "tcp://*:5555";
```

GUI 侧 (`zrcsGui/mainwindow.cpp`):
```cpp
zmqClient = new ZMQClient("localhost", 5555, this);
```

### 修改界面更新频率

编辑 `mainwindow_refactored.cpp`:
```cpp
updateTimer->start(100);  // 100ms = 10Hz
```

### 修改轴数

编辑 `zrcsConfig.h`:
```cpp
int axisCount = 5;  // 改为实际轴数
```

### 修改颜色方案

编辑 `zrcsStyles.h` 中的 `Colors` 命名空间。

## 故障排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| CMake 找不到 Qt5 | Qt 未安装或路径未设置 | 设置 `CMAKE_PREFIX_PATH` 指向 Qt 安装目录 |
| CMake 找不到 Protobuf | Protobuf 未安装 | `apt install libprotobuf-dev protobuf-compiler` |
| CMake 找不到 cppzmq | cppzmq 未安装 | `apt install libcppzmq-dev` |
| 编译报 C++17 错误 | 编译器版本过低 | 升级到 GCC 7+ 或 MSVC 2017+ |
| NRT 启动失败 | 共享内存创建失败 | 检查 Boost 安装，Linux 下检查 `/dev/shm` 权限 |
| GUI 显示"已断开连接" | NRT 未启动或端口被占用 | 先启动 NRT，检查 5555 端口 |
| ZMQ 连接被拒绝 | NRT 进程未运行 | 启动 `./bin/zrcsnrt` |
| Xenomai 未找到 | 仅 realtime 模式需要 | 安装 Xenomai 或使用 standard 模式 |
| CoppeliaSim 路径错误 | 仅 simulation 模式需要 | 修改 `controller.cmake` 中的路径 |

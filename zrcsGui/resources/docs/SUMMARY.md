## 🎨 7 大功能模块

### 1️⃣ 全局状态监控区 (Dashboard)
- 运行状态指示灯（空闲/运行/报警/急停）
- 通信状态显示（ZMQ、EtherCAT）
- 安全状态指示（回零、伺服使能）

### 2️⃣ 坐标与运动数据显示区 (Position Display)
- 5 个轴的实时坐标显示
- 多套坐标系（机械、绝对、相对）
- 动力学数据（速度、加速度）
- 伺服数据（扭矩、误差、温度）

### 3️⃣ 手动调试与示教区 (Jog Control)
- 5 轴点动控制按钮
- 步长设置（连续/10mm/1mm/0.1mm/0.01mm）
- 速度倍率滑块（0-100%）
- 单轴和全轴回零按钮

### 4️⃣ 轨迹与程序执行区 (Trajectory)
- 预留扩展空间
- 可添加 G-code 编辑器
- 可添加 2D/3D 可视化

### 5️⃣ 报警与诊断系统 (Alarms)
- 实时报警表格
- 完整的操作日志
- 清除和导出功能

### 6️⃣ I/O 与外设控制 (I/O Panel)
- 8 个输入监控（限位、急停等）
- 6 个输出控制（主轴、冷却液、气缸、继电器）
- 虚拟 LED 灯阵列

### 7️⃣ 参数配置与权限管理 (Settings)
- 预留扩展空间
- 可添加参数配置界面
- 可添加权限管理系统

## 🎯 核心特性

### 设计特点
✅ **深色主题** - 减少眼睛疲劳，适合长时间操作  
✅ **高对比度** - 工业现场光线复杂，确保清晰可见  
✅ **大按钮** - 便于工业现场操作，减少误触  
✅ **彩色编码** - 绿/蓝/黄/红 快速识别状态  
✅ **防误触** - 危险操作需要二次确认  

### 技术特点
✅ **模块化设计** - 易于扩展和维护  
✅ **双通道通信** - ZMQ + 共享内存自动故障转移  
✅ **实时更新** - 100ms 刷新率，<50ms 响应延迟  
✅ **线程安全** - 使用 Qt 信号槽机制  
✅ **配置灵活** - 集中式配置管理系统

## 🚀 快速开始

### 编译

```bash
cd c:\Users\64989\Desktop\zrcs-dev
mkdir build && cd build
cmake ..
make
```

### 运行

```bash
# 终端 1: 启动 NRT 进程
./bin/zrcsnrt

# 终端 2: 启动新 GUI
./bin/zrcsgui
```

### 切换到新界面

新的 CMakeLists.txt 已配置为使用新界面。如需使用旧界面，修改 CMakeLists.txt：

```cmake
set(SOURCES
    main.cpp  # 改为 main.cpp 使用旧界面
    mainwindow.cpp
    ...
)
```

```cpp
updateTimer->start(50);  // 改为 50ms (20Hz)
```
